# 제휴 광고(쿠팡 파트너스) 운영 메모

서비스 운영비를 마련하기 위해 `apps/web` 의 일부 화면에 쿠팡 파트너스 제휴 링크를
게재한다. 이 문서는 **게재 전에 반드시 끝나 있어야 하는 것**과 **공지 문안**을 한곳에
모아 둔 운영 기록이다. 광고 구좌의 코드는 `apps/web/src/features/ads` 가 담당한다.

| ---------- | ---------------------------------------------------------------- |
| 2026-11-24 | 개정 약관·개인정보 처리방침 배포 + **공지사항 게시** (아래 문안) |
| 2026-12-01 | 개정 시행일 = 광고 구좌 노출 시작 (`AD_LAUNCH_AT`)               |

개인정보 처리방침 제11항과 이용약관 제3조가 **"시행일 최소 7일 전 공지"** 를 스스로
약속하고 있다. 공지 게시일과 시행일 사이의 7일은 우리가 지켜야 하는 기한이므로,
공지를 올리지 않은 채 시행일을 앞당기면 방침 위반이 된다.

## 지켜야 하는 운영 규칙

**표기 의무.** 공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」상 경제적
이해관계 공개는 의무이며, **광고에 인접한 위치**에 쉽게 알아볼 수 있게 표시해야 한다.
푸터에 작게 숨기면 위반이다. 코드에서는 `features/ads/ui/ad-disclosure.tsx` 가 그 표기를
담당하므로, 구좌를 추가할 때 이 컴포넌트를 빼먹지 않는다.

**쿠팡 파트너스 정책.** (가입 후 최신 운영정책으로 재확인 필요)

- 가격·할인율을 우리 화면에 직접 쓰지 않는다 — 실시간으로 바뀌므로 표기 자체가 위험하다.
- "클릭해 주세요" 같은 클릭 유도 문구를 쓰지 않는다.
- 상품 이미지를 내려받아 우리 저장소에 올리지 않고, 쿠팡이 제공한 이미지 URL 을 그대로 쓴다.
- 본인·부원 구매는 수수료가 인정되지 않는다. 부원에게 "우리 링크로 사 달라"고 독려하는 운영은
  계정 정지 사유가 될 수 있으므로 하지 않는다.

**다루지 않는 상품.** 체중 감량 보조제·다이어트 약(체급 경기 종목에 유해한 메시지),
주류·도박, 효능·효과 표현이 필요한 의약외품.

**수익 귀속.** 쿠팡 파트너스 계정은 개인 명의로만 만들 수 있고, 수수료는 그 개인의
소득으로 귀속되어 3.3% 원천징수 대상이 된다. 누구 명의로 가입하고 동아리 회계로 어떻게
이관할지 사전에 합의하고 기록해 둔다. 학교 동아리 규정상 수익 활동에 제한이 없는지도
함께 확인한다.
