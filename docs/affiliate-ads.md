# 제휴 광고(쿠팡 파트너스) 운영 메모

서비스 운영비를 마련하기 위해 `apps/web` 의 일부 화면에 쿠팡 파트너스 제휴 링크를
게재한다. 이 문서는 **게재 전에 반드시 끝나 있어야 하는 것**과 **공지 문안**을 한곳에
모아 둔 운영 기록이다. 광고 구좌의 코드는 `apps/web/src/features/ads` 가 담당한다.

## 일정

| 날짜       | 할 일                                                            |
| ---------- | ---------------------------------------------------------------- |
| 2026-11-24 | 개정 약관·개인정보 처리방침 배포 + **공지사항 게시** (아래 문안) |
| 2026-12-01 | 개정 시행일 = 광고 구좌 노출 시작 (`AD_LAUNCH_AT`)               |

개인정보 처리방침 제11항과 이용약관 제3조가 **"시행일 최소 7일 전 공지"** 를 스스로
약속하고 있다. 공지 게시일과 시행일 사이의 7일은 우리가 지켜야 하는 기한이므로,
공지를 올리지 않은 채 시행일을 앞당기면 방침 위반이 된다.

## 공지사항 문안

[`docs/notices/2026-12-01-affiliate-ads.md`](./notices/2026-12-01-affiliate-ads.md) 에
본문 전문이 있다. 파일 맨 위 HTML 주석에 공지 제목이 적혀 있고, 그 아래 전체를
admin 공지사항 본문에 그대로 붙여넣으면 된다.

본문 렌더러(`apps/web/src/shared/ui/markdown.tsx`)는 `remark-gfm` 과
`remark-breaks` 를 쓴다. 표·제목·목록·링크는 그대로 되지만 **문단 중간의 줄바꿈이
`<br>` 로 렌더**되므로, 문안을 손볼 때 한 문단을 여러 줄로 쪼개지 않는다.

### 왜 공지를 해야 하는가

- 「개인정보 보호법」 제30조 제2항은 처리방침을 **변경**할 때 정보주체가 쉽게 확인할
  수 있도록 공개하도록 정한다. 공개 자체는 법정 의무다.
- 다만 "공지사항에 7일 전"이라는 기간은 법이 정한 것이 아니라, 개인정보위 표준
  개인정보 보호지침이 요구하는 **변경 전·후 비교 공개**의 취지와, 우리 처리방침
  제11항·약관 제3조 2항이 스스로 약속한 기한이다. 자기 약관을 지키지 않으면 변경의
  효력을 다툴 여지가 생기므로 법정 기간 유무와 별개로 지켜야 한다. 공지 문안에
  변경 전·후 대조표를 넣은 이유도 그 지침 때문이다.
- 수집 항목이 늘어나는 변경이 "동의가 필요한 사항"이면 고지가 아니라 **별도 동의**가
  필요하다(법 제15조). 광고 노출·클릭 기록을 식별자 없이 설계해(`ad_events` 에
  user_id·IP 컬럼이 없다) 개인정보 수집에 해당하지 않게 둔 덕분에 고지로 충분하다.
  로그에 식별자를 추가하려는 변경은 이 전제를 깨뜨린다.

## 지켜야 하는 운영 규칙

**표기 의무.** 공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」상 경제적
이해관계 공개는 의무이며, **광고에 인접한 위치**에 쉽게 알아볼 수 있게 표시해야 한다.
푸터에 작게 숨기면 위반이다. 코드에서는 `features/ads/ui/ad-disclosure.tsx` 가 그 표기를
담당하므로, 구좌를 추가할 때 이 컴포넌트를 빼먹지 않는다.

**쿠팡 파트너스 정책.** (가입 후 최신 운영정책으로 재확인 필요)

- 가격·할인율을 우리 화면에 직접 쓰지 않는다 — 실시간으로 바뀌므로 표기 자체가 위험하다.
- "클릭해 주세요" 같은 클릭 유도 문구를 쓰지 않는다.
- 상품 이미지를 내려받아 우리 저장소에 올리지 않고, 쿠팡이 제공한 이미지 URL 을 그대로 쓴다.
- 본인·부원 구매는 수수료가 인정되지 않는다. 부원에게 "우리 링크로 사 달라"고 독려하는 운영은
  계정 정지 사유가 될 수 있으므로 하지 않는다.

**다루지 않는 상품.** 체중 감량 보조제·다이어트 약(체급 경기 종목에 유해한 메시지),
주류·도박, 효능·효과 표현이 필요한 의약외품.

**기록 보관과 파기.** 광고 기록은 두 단계로 나눠 둔다.

- **원시 기록**(`ad_events`) — 3개월 보관 후 파기. 초 단위 시각과 페이지 경로가 남아 있어,
  같은 3개월을 보관하는 서버 접속 기록(IP + 접속 일시)과 시각으로 조인하면 접속자와
  연결될 여지가 있다. 결합 파트너가 사라지는 시점에 수명을 맞췄다.
- **일자별 집계**(`ad_daily_stats`) — 기간 제한 없이 보관. 시각과 경로가 없어 결합할 고리가
  없다. "어느 구좌·상품이 잘 되나", 전년 동월 비교 같은 운영 판단은 전부 이쪽으로 답한다.

둘 다 api 레포의 `startAdEventRetentionJob` 이 서버 프로세스 안에서 하루 한 번
**집계 → 파기** 순서로 처리한다. 외부 cron 설정이 필요 없으므로 배포만 하면 지켜지지만,
실제로 돌고 있는지 확인하려면 api 레포에서 `yarn ads:purge` 를 돌려 건수를 보면 된다.
집계가 실패하면 파기도 하지 않는다 — 접지 못한 날의 원시 로그를 지우면 되돌릴 수 없다.

**수익 귀속.** 쿠팡 파트너스 계정은 개인 명의로만 만들 수 있고, 수수료는 그 개인의
소득으로 귀속되어 3.3% 원천징수 대상이 된다. 누구 명의로 가입하고 동아리 회계로 어떻게
이관할지 사전에 합의하고 기록해 둔다. 학교 동아리 규정상 수익 활동에 제한이 없는지도
함께 확인한다.
